# 🔐 Microsoft Purview Labs

This folder contains hands-on labs and technical documentation related to **Microsoft Purview** data security and compliance technologies.

The labs focus on practical configuration, testing, policy enforcement, data classification, monitoring, investigation, and policy tuning using Microsoft Purview in a test environment.

## 📚 Labs

Individual lab folders contain:

- Step-by-step implementation documentation
- Policy and configuration details
- Data protection scenarios and use cases
- Architecture and workflow explanations
- Screenshots and validation evidence
- Enforcement testing and observations
- Monitoring and investigation results

## 🎯 Areas Covered

The labs in this folder explore Microsoft Purview capabilities such as:

- Data Loss Prevention (DLP)
- Endpoint Data Loss Prevention
- Sensitive Information Types (SITs)
- Exact Data Match (EDM)
- Trainable Classifiers
- Information Protection and Auto-labeling
- Microsoft 365 workload protection
- DLP policy testing, enforcement, and tuning
- Activity monitoring and alert investigation

> **Note:** These labs are performed in a test/demo environment for learning, experimentation, and technical documentation purposes.

This is a **continuous learning portfolio** and will be expanded with additional Microsoft Purview labs, security scenarios, integrations, and advanced data protection use cases as the learning environment evolves.
